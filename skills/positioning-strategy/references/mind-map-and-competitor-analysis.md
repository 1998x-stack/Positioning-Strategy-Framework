# Mind Maps and Competitive Analysis — 心智地图与竞争分析

## 三种图必须分开

### 1. 品类心智阶梯
展示受访者在明确品类中的品牌回忆或考虑排序。建议字段：品类定义、样本/地区/时间、无提示第一提及率、无提示总提及率、辅助认知率、考虑率、首选率、来源和置信区间（适用时）。

不能把市场份额直接当作心智排名，也不能把搜索热度直接当作偏好。

### 2. 品牌联想网络
记录功能属性、典型场景、情绪身份、价格/质量印象、服务体验、信任来源、负面联想、出现频率和来源。词云不能表达强度、方向、因果或代表性。

### 3. 感知地图
二维轴必须来自客户重视且可测量的维度：
1. 访谈探索比较维度。
2. 问卷测量属性重要性和品牌表现。
3. 检查维度是否相关、可区分。
4. 选择可解释维度展示。
5. 标注样本、测量口径和不确定性。

不要为了漂亮四象限随意指定“高端/低端”“传统/创新”等轴。

## 竞争集合
每个客户任务至少识别直接竞品、间接替代、邻近品类、现有供应商/自有方案、继续使用旧方案、延迟购买和不行动。

## 竞争矩阵字段

| 字段 | 说明 |
|---|---|
| Competitor | 品牌/方案及法律主体 |
| Frame | 客户实际比较的品类 |
| Segment | 目标客户和使用情境 |
| Claimed position | 对外宣称的位置 |
| Observed association | 客户真实联想 |
| Proof | 可核验的证据 |
| Price/TCO | 价格、总拥有成本和切换成本 |
| Channel | 可获得性、渠道和覆盖 |
| Strength | 竞争者真实优势 |
| Weakness | 有证据的不足，不是主观贬义词 |
| Threat | 可能复制或反制的方式 |
| Source IDs | 来源编号 |
| Confidence | 研究者置信度 |

## 必答问题
谁是默认第一选择？谁是最常比较的替代？客户如何定义“好”？哪些差异重要但未被满足？哪些差异只是企业自己重视？竞争者是否已宣传该差异？客户是否相信？该位置能否带来利润而不只是关注？
