# Strategic Fit and Validation — 战略配称与验证

## 定位必须落到经营系统

| 维度 | 审查问题 | 常见失配 |
|---|---|---|
| 产品 | 是否交付承诺差异？ | 广告说专业，体验普通 |
| 质量 | 性能是否可重复？ | 只展示单次最好结果 |
| 价格 | 与价值感知和经济性一致吗？ | 高端定位长期依赖无差别折扣 |
| 渠道 | 目标客户能方便买到吗？ | 定位高端但服务不匹配 |
| 服务 | 交付和售后支持承诺吗？ | 承诺快速响应但没有网络 |
| 品牌 | 名称、视觉和内容一致吗？ | 核心表达频繁变化 |
| 组织 | KPI和激励鼓励正确行为吗？ | 销售只追规模牺牲质量 |
| 供应链 | 产能、质量和交付稳定吗？ | 增长后无法兑现 |
| 经济性 | 获客、毛利、复购和现金流成立吗？ | 高销售额但低贡献利润 |

## 验证阶梯
1. 理解：客户能否用自己的语言复述？
2. 相关：问题真实存在吗？频率、痛感、预算如何？
3. 差异：客户能说出与替代方案的区别吗？
4. 可信：客户相信吗？需要什么证据？
5. 选择：在真实价格和真实替代品下影响购买吗？
6. 试点：交付、毛利、留存、服务负担和渠道适配成立吗？

## 实验设计
可考虑随机概念测试、地理/账户 holdout、分阶段 rollout、价格/选择实验、可比客户队列、中断时间序列或满足前提的差分中的差分。实验前定义假设、主指标、护栏指标、样本、分组、观察期、成功/失败阈值和偏差风险。

## 归因边界
增长可能来自价格、渠道、销售团队、广告预算、促销、新产品、并购融资、行业增长、竞争者退出或宏观环境。没有合适对照或反事实时，应写“与定位调整同期发生”或“可能相关”，不能写“定位导致增长”。

## 复盘频率
试点期每周检查交付和反馈；上市后每月检查认知、转化和单位经济；稳定期每季度复核竞争与认知；技术、法规、渠道或客户行为重大变化时专项复核。
