# Core Theory — 定位理论核心概念

## 定位不是产品改造的同义词
定位首先是客户如何理解一个品牌/产品，以及它相对于其他选择处于什么位置。产品事实、服务体验和运营能力决定认知能否兑现，但不能直接等同于定位。

## 定位不是广告语

| 概念 | 回答的问题 |
|---|---|
| 企业战略 | 企业选择在哪些业务竞争、如何配置资源 |
| 市场细分 | 哪些客户群体有不同需求或行为 |
| 品类/竞争框架 | 客户把哪些选择放在一起比较 |
| 品牌定位 | 品牌在目标客户认知中代表什么 |
| 价值主张 | 客户为什么应该考虑该方案 |
| 定位陈述 | 内部战略决策的结构化表达 |
| 广告语 | 面向传播的简短表达 |
| 品牌形象 | 客户长期形成的综合印象 |

一句广告语可以很响亮，却没有目标客户、竞争参照、差异点和证据，因此不构成完整定位。

## 心智是有限注意力系统
“心智阶梯”适合作为战略启发式模型：客户会简化选择，并形成品类内的品牌排序和联想。但它不是神经科学模型，也不能替代消费者研究。

至少区分：
- 无提示回忆：不提示品牌时首先想到什么？
- 辅助认知：给出列表后是否认识？
- 品牌联想：想到品牌时会说什么？
- 考虑集：购买时会认真考虑哪些选项？
- 选择/复购：认知是否转化为真实行为？

## 品类先于差异点
差异必须在比较框架中才有意义。“更快”要说明相对于什么方案、在什么情境、以什么口径更快。先识别客户自然使用的品类，再判断是否值得重构品类或创造子品类。

## 第一的多种含义
“第一”可能指最早上市、最先进入心智、市场份额第一、细分品类第一或某项技术指标领先。这些概念不能混用。没有来源、地区、品类和时间范围时，不得使用“第一”“领先”“最大”等主张。

## 领导者与跟随者
领导者通常维护核心认知并持续兑现价值。跟随者不应机械复制，而应寻找相关、可交付且经济成立的差异。细分空位可能来自人群、场景、时间、价格、尺寸、渠道或使用任务；空位必须验证需求。

## 重新定位竞争者
重新定位不是攻击对手，而是改变客户理解选择的比较框架。比较必须同口径、可核验、说明适用条件，避免虚假暗示和贬损推断。

## 名称与品牌延伸
名称影响发音、记忆、搜索和品类理解。品牌延伸不是一律成功或失败，应评估品类距离、联想迁移、品牌稀释、价格/渠道冲突、客户理解、独立品牌与子品牌成本。

## 现代化补充
本框架增加细分研究、客户任务分析、证据登记、单位经济、反向证据、实验验证、数字渠道和防御性分析。这些是现代方法扩展，不应冒称为原书原始模型。
