# Contributing

## Principles
- Evidence before assertion.
- Customer relevance before novelty.
- Commercial viability before attractive wording.
- Counter-evidence before causal claims.
- Reusable methods over one-off consulting language.

## Adding a case
1. Start from templates/case-study.md.
2. Add traceable sources and source grades.
3. Connect each claim to source IDs.
4. Record counter-evidence and unresolved questions.
5. Separate evidence quality from causal-attribution confidence.
6. Mark synthetic data explicitly.
7. Run scripts/validate_case.py.
8. Add tests if validation logic changes.

## Changing the framework
- Update the canonical skill first.
- Update the relevant reference.
- Keep agent entry points as short pointers.
- Run the full validation suite.

## Copyright
Do not submit scans, copied chapters, long extracts, or unlicensed assets. Use original summaries, bibliographic references, and links to authorized sources.
