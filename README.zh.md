# Positioning Strategy Framework｜定位战略框架

**把《定位》从一本营销经典，转化为可研究、可验证、可执行、可复用的战略工作流。**

本项目是一套面向企业、品牌、产品、服务、机构与个人职业的研究型 Agent Skill。理论起点是艾·里斯与杰克·特劳特《定位：争夺用户心智的战争》中文22章经典重译版；同时补充现代市场研究、竞争分析、证据审计、商业模型和实验验证。

> 定位不是替企业想一句广告语，而是选择一个有需求、有差异、有证据、能兑现、可持续的竞争位置。

## 为什么需要这套框架

常见的低质量定位工作会把企业介绍改成广告语、罗列“技术领先/品质卓越/服务一流”、只研究竞品广告、把无人占据的空白误判成机会，或者用销售增长直接证明定位成功。

本框架要求先理解客户、品类和竞争环境，再形成定位假设，最后检查产品、价格、渠道、运营和经济性，并用客户与市场证据验证。

## 核心工作流

~~~mermaid
flowchart TD
 A[明确业务决策与研究边界] --> B[市场、客户与品类研究]
 B --> C[竞争格局与心智地图]
 C --> D[识别定位机会与战略选项]
 D --> E[形成定位陈述与证据链]
 E --> F[产品、价格、渠道、组织和经济性审查]
 F --> G[客户验证与市场实验]
 G --> H[执行、监测与复盘]
 G -->|证据不支持| D
~~~

## 七个模块

| 模块 | 核心问题 | 主要产出 |
|---|---|---|
| 理论知识库 | 定位理论的概念、边界和适用条件是什么？ | 22章知识地图、原则卡片 |
| 竞争分析 | 客户把谁放在同一选择集合？ | 品类地图、竞争矩阵、替代方案 |
| 心智地图 | 客户如何记忆、排序和关联品牌？ | 心智阶梯、联想图、感知地图 |

| 案例验证 | 定位决策与经营结果之间有什么证据？ | 案例档案、反证、因果置信度 |

## 交付标准

完整项目应包含研究范围、市场与客户任务、品类和替代方案、当前认知、竞争矩阵、心智地图、定位选项、机会评分、定位陈述、信任状、战略配称、验证方案、证据登记、反向证据和实施路线图。

## 证据纪律

本框架分别评估：

- **证据质量**：某项事实是否有可靠来源支持？
- **因果归因**：该事实是否足以证明定位导致了某个经营结果？

例如，审计报告可以高质量证明收入增长，但不能单独证明收入增长由定位造成。还需检查营销投入、渠道扩张、价格、产品迭代、竞争者变化和行业周期。

| 等级 | 证据质量 | 因果归因 |
|---|---|---|
| A | 监管、审计、法定披露、原始实验数据 | 随机实验或严谨因果设计 |
| B | 可信独立媒体、行业研究、可复核记录 | 有对照和混杂因素处理的强时间序列 |
| C | 企业/咨询机构宣传、当事人访谈 | 前后对比或存在明显混杂的相关性 |
| D | 推断、传闻、无来源数字 | 无法建立可靠归因 |

每条主张单独评级，不能给整个案例笼统贴一个等级。

22章目录映射见 [book-chapter-map.md](skills/positioning-strategy/references/book-chapter-map.md)。本项目使用原创语言归纳理论，不复制书籍正文。研究协议、评分模型、证据等级、因果归因和实验验证属于现代操作化扩展，不应误称为原书作者的原始模型。

## 边界

- 不得把虚构示例当作真实客户案例。
- 不得把企业宣传伪装成独立第三方证据。
- 不得使用未经核验的市场份额、消费者认知或广告效果数字。
- 不得通过诋毁或不可证实的比较主张建立定位。
- 当前仓库未授予开源许可证；未经所有者另行授权，不应假定可以自由复制、修改或再分发。
